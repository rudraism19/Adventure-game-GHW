A small, self-contained pixel-art adventure game about Mona exploring a mossy island. No installation or build step is required — just open `index.html` in a browser and play.

<details open>
<summary><strong>🎮 Quick start</strong></summary>

1. Open `index.html` in your browser.
2. Start the game from the title screen.
3. Collect all five fish.
4. Avoid the crabs and make it to the island gate before losing all three lives.

</details>

<details>
<summary><strong>🕹️ Controls</strong></summary>

- Move: Left/Right arrow keys or `A` / `D`
- Jump: `Space`, Up Arrow, or `W`
- Pause: `Esc` or the pause button
- Restart: the restart button
- Touch screens: use the on-screen arrow and jump buttons

</details>

<details>
<summary><strong>🌊 Objective</strong></summary>

Mona needs to gather every fish scattered across the island, dodge the crabs, and reach the glowing gate at the end of the level. Each time she is hit, a heart is lost, and the run ends when all three lives are gone.

</details>

<details>
<summary><strong>✨ Features</strong></summary>

- Pixel-art island setting
- Keyboard and touch controls
- Pause and restart flow
- Score tracking for collected fish
- Three-life challenge loop

</details>
