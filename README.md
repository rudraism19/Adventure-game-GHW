# Mona and the Mossy Isles

A small, self-contained pixel-art adventure game. Open `index.html` in a browser to play; no installation or build step is required.

Collect all five fish, avoid the crabs, and reach the island gate. Mona has three lives.

- Move: left and right arrow keys or A and D
- Jump: Space, the up arrow, or W
- Touch screens: use the on-screen arrow and jump buttons
- Pause: Esc or the pause button
- Restart: the restart button
